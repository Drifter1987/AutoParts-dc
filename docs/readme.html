AutoParts
Project status · November 2026
Open the live app

One real VIN → part slice, with the limits stated.

AutoParts is a frontend-only React/Vite app deployed to GitHub Pages. There is no Supabase project, FastAPI service, admin dashboard, or account system in the current build. VIN decoding and recall lookup call public NHTSA APIs directly from the browser.

The 2020 Honda Civic parts catalog is a representative product-development dataset, not licensed OEM data. Part numbers, fitment, and availability must be verified with an authorized dealer before ordering.

What is live now

Live · VIN decoder

NHTSA vPIC decode with make, model, year, engine, trim, plant, and recall lookup. A decoded 2020 Civic hands off to the matching catalog.

Live · Civic vertical slice

Model-year page, four assemblies, 36 parts, fitment notes, supersessions, interchange numbers, provenance, and assembly → part navigation.

Live · Search and carry

OEM/name/alias search with VIN context, copyable numbers, print parts sheets, shareable URLs, and local My Garage. No account required.

Preview · Brand/model catalog

63 active US-market brands, 1,249 models, and 3,577 EPA-sourced engine configurations are catalogued. Only the 2020 Civic has parts data today; the catalog is not a complete global historical registry.

Slice · Exploded diagram

One representative 2D schematic with numbered hotspots and keyboard-accessible text links. It is not an OEM drawing.

Planned · Licensed scale

Licensed OEM data and diagrams, fitment validation, more vehicles, pricing/stock, 3D, and accounts are not built.

Data pipeline

npm run validate:parts runs before every build. It rejects duplicate OEM numbers/slugs, missing provenance fields, unknown engines or trims, empty assemblies, and a part count outside 30–50 for the slice. See parts-provenance.md for the license/provenance policy.

npm run prerender generates static HTML for every route and sitemap.xml. robots.txt points crawlers at the sitemap.

Verification status

  • TypeScript and ESLint pass.
  • Playwright smoke tests cover VIN decode, Civic navigation, OEM search, recalls, garage, and metadata.
  • Deployed Pages tests verify static metadata without JavaScript.
  • Recall data is matched by year/make/model; the authoritative open-recall check is by VIN on NHTSA.
  • The 5–8 mechanic/parts-counter usability sessions are not run; the protocol is in usability-test-plan.md.

Known limitations

  • One vehicle/year with representative data; no licensed OEM feed.
  • No prices, stock, retailer checkout, or account sync.
  • Camera VIN scanning depends on browser BarcodeDetector support and a Code 39 label.
  • My Garage is local to one browser; clearing site data removes it.
  • Analytics/error reporting is an optional endpoint boundary; no third-party collector is configured.
